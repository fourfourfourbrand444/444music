Fix Stale User IDs
Scans every submission and checks the stored userId field against the real, currently-existing user account for that submission's email. This catches releases that went invisible on the artist dashboard (and Flutter app) because the account behind that email was deleted and recreated — Firebase issues a brand new UID, but the old submission docs still point at the dead one. Fixing the field here updates Firestore directly, so the web dashboard, the Flutter app, and any future client all pick up the correction automatically — nothing to redeploy anywhere.
