Set Follower Count

Writes one number to the followersCount field on the user doc — nothing else. No subcollection documents are created. The real "Followers" list (who actually follows this account) is completely separate and untouched, so it will always show the real people regardless of what this number says. Once viewpro.html is updated to read this field (like the app already does), the number you set here shows on both app and web identically.
