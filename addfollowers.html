Add Followers (dev tool)

Adds real documents to users/{uid}/followers for a target account, and increments its followersCount field to match. This is the actual subcollection viewpro.html reads live — so the number on the profile page will update for real, not just cosmetically.

Note: the fake follower IDs won't correspond to real user accounts, so if that account's "Followers" list modal is opened, these entries will show up as generic "Artist" placeholders (no name/avatar). Fine for a display-count boost, not meant to simulate real engaged users.
